# Styling Paradigms

This project demonstrates modern CSS styling approaches using React.

## Exercises

### Exercise 1 – Tailwind CSS
- Developed a responsive product dashboard.
- Created reusable components for the header, sidebar, and product cards.
- Implemented responsive layouts using Tailwind CSS utility classes.
- Applied hover, focus, and disabled states.
- Used consistent design tokens for colors and spacing.

### Exercise 2 – Vanilla Extract
- Developed a reusable component library.
- Created Button, Card, and Badge components.
- Implemented Primary, Secondary, and Danger button variants.
- Added Small and Large button sizes.
- Implemented Success, Warning, and Error badge variants.
- Used shared design tokens for consistent styling.
- Implemented build-time CSS generation.

## Technologies Used
- React
- JavaScript
- Tailwind CSS
- Vanilla Extract
- Vite

## Installation and Setup

Clone the repository:

````bash
git clone https://github.com/teeshagabalersl/styling-paradigms.git
````

Navigate to the project directory:

````bash
cd styling-paradigms
````

Install dependencies:

````bash
npm install
````

Start the development server:

````bash
npm run dev
````

Build the project:

````bash
npm run build
````
